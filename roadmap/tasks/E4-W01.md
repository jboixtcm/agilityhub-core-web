# E4-W01 · D3 + D3b — weekly templates (/plantilles): template tabs, band × day grid, class form with automatic description, inconsistencies, generation card + SETMANES table, coverage table, day view per ring / per instructor

## Objective
Work package S06 P4: the administrator designs the weekly offer in D3 (one Mon–Fri template with the A/B alternation, one Saturday template, both as tabs behind «Plantilles»), creates classes in the band × day grid with the automatic description and a persistent manual override, sees inconsistencies on the cell and in the footer note, generates a week as a draft from the generation card, reads the coverage table with the D3 vocabulary, and opens the day view per ring / per instructor (D3b). The instructor sees everything read-only (decision A22 c). Mocks-first on the S06 contract published by api E4-T01; pixel-faithful to the V7 mockups.
