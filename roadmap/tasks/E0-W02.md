# E0-W02 · packages/ui: design tokens → CSS variables, BrandingProvider, base components, icon sprite from the mockups

## Objective
Work package WP-02-C (ui part): a themable design system so every club looks like its own product, built from the visual language of the approved mockups.

## Spec references
S02 R-02-08 and test **T-02-05** (tokens + color lint) · `docs/PLA_FRONTEND.md` §4 (design system) · `docs/pantalles/**/*.html` (typography Montserrat, radii, chips, level colors, icon `<symbol id="i-*">` sprites).

## Context to load
S02 §4 (theme), PLA_FRONTEND §4, three or four mockup HTML files (e.g. `docs/pantalles/mobil/03-inici-abonat.html`, `04-reservar-*.html`, `docs/pantalles/escriptori/D1-tauler-de-control.html`, `D5-*.html`) · this file.

## Steps
1. `packages/ui/src/tokens.css`: CSS variables `--ah-color-{primary, primary-fg, surface, surface-2, text, text-muted, border, success, warning, danger, info}`, `--ah-radius-{sm,md,lg,full}`, `--ah-font-{sans,display}`, `--ah-space-*`, with the **AgilityHub default theme** (the «club mínim» look); Tailwind 4 `@theme` mapping the variables (`bg-primary`, `text-muted`, …); `mode` `auto|light|dark` via `color-scheme` + a `[data-theme]` attribute.
2. `BrandingProvider({ branding })`: applies `Club.theme` (the `/branding` response shape from the core: `theme.colors.*`, `logoUrl`, `markUrl`, `fonts`, `mode`) to the variables on `document.documentElement`; exposes `useBranding()` (club name, logos, locales, modules, countryProfile, signup); warns in console when primary/primary-fg contrast is below AA.
3. Components (typed props, accessible, one Testing Library test each, `*.stories.tsx` optional): `Button` (primary/secondary/ghost/danger, loading), `IconButton`, `Chip` (`tone`: neutral/success/warning/danger/info — used for states like «activa», «en risc», «anul·lada», «no presentat»), `Badge` (counter), `Card`, `Input`, `Textarea`, `Select`, `Checkbox`, `Switch`, `RadioGroup`, `FormField` (label, help, error), `Modal`, `Drawer` (desktop side panel), `Toast` (queue + `useToast`), `Tabs`, `AppBar` (mobile), `TabBar` (mobile, 6 tabs), `Sidebar` (desktop, grouped entries + counters), `EmptyState`, `Skeleton`, `Avatar` (person/dog initials), `LevelDot` (level color), `DataTable` base (header, rows, empty, loading — the universal filter comes in E2).
4. `packages/ui/src/icons/`: extract every `<symbol id="i-…">` from the mockup HTML files (script `scripts/extract-icons.mjs` that scans `docs/pantalles/**/*.html`, deduplicates by id and writes one sprite + an `Icon name="home"` component with a typed union of names). Keep the ids from the mockups (`home`, `cal`, `cone`, `day`, `user`, `info`, …).
5. `apps/clubs-admin/src/dev/gallery.tsx` (route `/_gallery`, dev only): renders every component in the AgilityHub theme and, with a toggle, in the Cànic theme (fixture `packages/api-client/src/mocks/fixtures/branding-canic.json` — create it now from the mockup colors; E0-W04 will reuse it).
