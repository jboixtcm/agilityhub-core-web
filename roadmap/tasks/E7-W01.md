# E7-W01 · D9 + the notification log + the D10 preferences block + the announcement dialog (S11 WP-11-D)

## Objective
Work package S11 WP-11-D: the administrator maintains every notification template from D9 (title, body per language, SMS short text, icon, colour, the channel × audience matrix limited to the code's `caps`), previews it with the fictional data set, sends herself a test, restores the product default, disables or deletes it; sends a mass announcement from D9 or from a D5/D15 selection with a confirmation that states how many members it reaches; reads the club's notification log; and maintains a member's alert preferences from the D10 block. Everything the API decides — categories, audiences, `caps`, `push`, variables, `mandatory`, the rendered preview, the recipient count — is rendered as delivered; the front never widens a matrix, never renders a template itself and never recomputes a recipient set. Mocks-first on the S11 schemas of api E7-T01; pixel-faithful to the V7 mockups at 1280 px.
