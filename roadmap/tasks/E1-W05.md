# E1-W05 · Footer location from the branding contract (`club.city`) — remove the club literal left by E1-W01

## Objective
E1-W01 shipped the access-screen footer «{club} · {població}» with `t("auth:access.locationCanic")` selected by `branding.club.slug === "canic"`. That is a club literal in code (AGENTS.md §2: nothing Cànic-specific in code — parameters, catalog, seeds or fixtures only). The organizer has extended the `/branding` contract: `club.city` (optional string, from the club's `address.city`). Make the footer fully tenant-driven and delete the literal.

## Spec references
S01 §2 (screen 01 footer) · `docs/specs/00-transversal/CONVENCIONS_API.md` (contract in the OpenAPI stub until the api snapshot is synced) · AGENTS.md §2.

## Context to load
`apps/clubs/src/App.tsx` (footer around the `branding.club.slug === "canic"` conditional) · `packages/api-client/openapi/stub.json` (`BrandingResponse.club`) · `packages/api-client/src/mocks/fixtures/branding-canic.json` · `packages/i18n/src/locales/{ca,es,en}/auth.json` · the E1-W01 tests T-01-18 (unit + e2e) · this file.

## Fixed conventions
- Contract (organizer decision 06-09, mirrored to the api as part of E1-T02): `BrandingResponse.club = { slug: string, name: string, city?: string | null }`. No other new field.
- Footer rendering: `city` present and non-blank → `{name} · {city}`; otherwise `{name}` alone (no dangling separator). One i18n key with ICU/interpolation is fine, e.g. `auth:access.footer` = `"{club} · {city}"` and `auth:access.footerNoCity` = `"{club}"` — or a single key with a conditional; never a literal town name in any locale file.
- The town name lives only in fixtures/seeds: `branding-canic.json` gets `"city": "Cabrera de Mar"`; `branding-minim.json` gets no `city` to exercise the fallback.

## Steps
1. `packages/api-client/openapi/stub.json`: add `city` (`type: string`, `nullable: true`, not required) to the branding `club` schema; regenerate the types (`pnpm --filter @agilityhub/api-client api:generate`).
2. `branding-canic.json`: add `"city": "Cabrera de Mar"` under `club`.
3. `apps/clubs/src/App.tsx`: replace the slug conditional and the `locationCanic` key by the contract-driven footer (both branches).
4. `packages/i18n`: delete `auth:access.locationCanic` in `ca`, `es`, `en`; add the footer key(s) in the three locales.
5. Tests: extend T-01-18 (unit) with (a) Cànic fixture → footer «Club Agility Cànic · Cabrera de Mar», (b) a branding without `city` → footer = club name only, no «·»; keep the e2e assertion of the footer text.
6. `grep -rni "cabrera\|locationCanic" apps packages --include=*.ts --include=*.tsx --include=*.json` must return only `branding-canic.json` and tests/fixtures.
