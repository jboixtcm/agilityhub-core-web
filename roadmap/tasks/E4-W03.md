# E4-W03 · Screens 10 «Classes del dia» (/avui) and 23 «Visió global» (/instructor/avui) — shared DayGrid in packages/ui, «Ocupada» state, risk balloon, student view without counts, instructor global view

## Objective
Work package S06 P6: the student sees the day as a ring × time grid (screen 10: description + instructor only when the api sends it, «Ocupada» cells without saying who, the at-risk class with its balloon, never a count — decision A22 e) and the instructor sees the whole club at a glance (screen 23: `n/n +e`, the planned instructor always, training bookings with names, ring blocks, cancelled classes dimmed). Both screens render `GET /day-grid` (form D) through one shared `DayGrid` component in `packages/ui`, also used by the desktop day views of E4-W01/E4-W02. Mocks-first on the S06 contract of api E4-T01; pixel-faithful to the V8 mockups at 375 px.
