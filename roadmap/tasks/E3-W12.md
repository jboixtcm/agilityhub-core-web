# E3-W12 · Screen 13 without `/parameters`

## Objective
Screen 13 (`MyDogsPage` in `apps/clubs/src/SelfServicePages.tsx`) reads `census.dogDocumentTypes` and `levels.enabled` from `GET /parameters/{key}` as the member. The api allows `/parameters/*` only to a non-impersonated ADMIN (`SettingsController`, MATRIU_PERMISOS). On the real core both reads get 403, and `optionalParameter` hides the error:
- «＋ DOC.» offers only the vaccination card, so a member cannot upload the insurance or any other type (R-03-15);
- «Nivell {codi}» follows a default instead of the club's `levels.enabled` (R-03-30).

The mocks still answer members, so no test sees it. The E4-W08 executor reported it. S03 was amended on 25-09, and api E3-T16 adds `documentTypes` to `GET /me/dogs`. The organizer opens this task once E3-T16 is published. It must be done before the gate re-run E3-W09, which depends on this task.
