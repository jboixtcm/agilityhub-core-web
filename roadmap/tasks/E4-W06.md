# E4-W06 · D11 «Nivells» — «Progressió» switch (E29)

## Objective
This task implements the organizer ruling E29 of 2026-09-24 (`docs/DECISIONS_PENDENTS.md`):
- a level can be outside the progression of levels (the Cànic's «Teràpia» is);
- only progression levels count for the automatic description «{first} i sup.».

The admin sets this per level in the D11 «Nivells» card.
