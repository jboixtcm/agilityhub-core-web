# E6-W01 · Screens 20, 21 and 22 — the instructor's day and the attendance sheet (S10 front, mobile)

## Objective
Work package S10 WP-10-D (mobile half) plus the mobile half of WP-10-E: the instructor opens her day (20), taps a class, marks one circle per dog on the sheet (21) — white `PENDING`, green `PRESENT`, yellow `NOTIFIED` («ha avisat»), red `NO_SHOW` («no presentat») — saves the whole list in one `PUT`, and opens a dog's card (22) with the 30-day metrics, the five last classes and the three `TASKS` blocks. Every decision is the api's: the front never computes the edit window, the `late` flag, a metric or a badge — it renders `sheet.canMarkPresence`, `canMarkNotice`, `editableUntil`, `row.final`, `notice.*`, `noShowNotice.*` and `metrics.*` as delivered, and re-reads the sheet when the version is stale. Mocks-first on the S10 schemas of api E6-T01; pixel-faithful to the V8 mockups at 375 px.

## Fixed conventions
- Design system only; no literal colours (ring colours and circle tones through CSS custom properties and tokens); keys never literals; ca/es/en together; vocabulary rules (never «parell*», «amigable», «(paràmetre)» or requirement codes; the red state is «no presentat», never «no assistit»).
- The api decides: window, permissions, `final`, `late`, `seatReleased`, `waitlistNotified`, metrics, `displayState` and badges are rendered as delivered; the front never recomputes a threshold, a percentage or a state machine beyond the local draft, and never calls the cancellation endpoint itself (marking `NOTIFIED` is what cancels, inside the api transaction).
- Dates and times through `packages/i18n` formatters with the club `timeZone`; «today» is club-local (S06 R-06-14); instants arrive UTC.
- Errors are handled by `code` through `errors:<CODE>` — never by HTTP status and never by rendering the api `message` as copy.
- Closed catalogs: no new parameter, event, notification or error code. Proposed literals («llista passada», «Cap classe aquest dia», «avís ja enviat», «sense marcar», the 409 toast, the FIFO sentence, `shell:nav.myDay`, `shell:nav.students`) go to the report and `roadmap/MESSAGES.md` as proposals — they ship meanwhile with the wording above (S10 §13-11 leaves them to Josep's literal review).
