# E0-W03 · packages/i18n: ICU, namespaces, club-aware formats, parity/vocabulary/unused-key checks

## Objective
The i18n foundation: three locales from day one, ICU plural/gender, formats in the club's time zone and currency, and CI checks that keep translations complete and the vocabulary clean.

## Spec references
`docs/specs/00-transversal/CONVENCIONS_I18N.md` (namespaces, key style, formats, forbidden vocabulary) · `docs/decisions/ADR-011` · S02 T-02-17 (mechanism) · `docs/specs/00-transversal/CATALEG_ERRORS.md` (every code needs a message).

## Context to load
CONVENCIONS_I18N · ADR-011 · CATALEG_ERRORS · this file.

## Steps
1. `i18next` + `react-i18next` + `i18next-icu`; locales `ca`, `es`, `en`; namespaces `common`, `auth`, `shell`, `errors` (others per stage); lazy loading per namespace; language resolution: user (`me.account.locale`) → `branding.locales` ∩ browser languages → `branding.defaultLocale`.
2. `format.ts`: `formatDate`, `formatTime`, `formatDateRange`, `formatDuration` («2 h», «30 min», «4 h abans» / «4 h before»), `formatMoney` («45,00 €» / «€45.00») using `Intl` with the club `timeZone` and `currency` (`useClubFormats()` hook reading `useBranding()`); unit tests for `ca`, `es`, `en`.
3. `errors` namespace: a message for **every** error code in `CATALEG_ERRORS.md` in the three locales; script `scripts/check-error-codes.mjs` comparing the document's codes with the keys.
4. `pnpm i18n:extract` (i18next-parser config) and `pnpm i18n:check` (`scripts/i18n-check.mjs`): (a) key parity ca/es/en, (b) no key used in code without a translation, (c) no empty values, (d) **forbidden vocabulary** in translation files and in `.tsx` string literals: `parell`, `parella`, `amigable`, `(paràmetre)`, `\bF\d+\b`, `\bRF-`, `\bBR-`; exit code 1 on any failure with a readable list.

## Verification (run all; paste full output in the report)
- `pnpm --filter @agilityhub/i18n test && pnpm i18n:check` → green.
- Add a key only to `ca` → `pnpm i18n:check` fails naming the key; add the word «parella» to a translation → fails naming the file; revert both (paste outputs).
- `node scripts/check-error-codes.mjs` → «N codes, 0 missing».

## Definition of Done
Three locales complete for `common/auth/shell/errors` · checks proven · formats tested.

## Evidence to return
Outputs above; key counts per locale.
