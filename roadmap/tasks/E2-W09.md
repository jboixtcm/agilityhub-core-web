# E2-W09 · D11 «Pàgines del club» editor (rules, privacy, image consent, welcome guide) + screen 30 «Info» tabs (ClubPage contract of api E2-T12)

## Objective
The club maintains its own texts from D11 and the students read them in the app «Info» page; the public signup links the rules page. Replaces the disabled «Normes del club» link of E2-W05.

## Spec references
S05 §6 rows `/club-pages*` and `/public/{clubSlug}/pages/{key}` · S05 §11 **T-05-CP-07** (front) · S05 change log 05-09 (`ClubPage`, «editor per idioma + vista prèvia») · R-05-21b (provisional marker text «[Text pendent — el club l'omplirà des de Paràmetres]» stays visible until the club edits it) · S11 change log 05-09 (screen 30 «Info» tabs FAQ · Normes · other active pages) · S04 change log 05-09 (screen 19 link «Normes del club: consulta-les aquí», no checkbox — the signup screen itself is E3) · mockup `docs/pantalles/escriptori/D11-*.png` (card «Pàgines del club» next to the FAQ card), `docs/pantalles/mobil/30-*.png` («Info»).

## Context to load
S05 §6 (the three `club-pages` rows) · the FAQ card/editor of E2-W04 (`apps/clubs-admin/src/catalogs/*`) and the D11 card of E2-W05 · `apps/clubs` screen 30 «Info» (FAQ accordion) · the api snapshot with `ClubPage` (`GET/POST/PATCH /api/v1/club-pages`, `GET /api/v1/public/{clubSlug}/pages/{key}`) · this file.

## Steps
0. **Contract**: api E2-T12 publishes `ClubPage {key, title: LocalizedText, body: LocalizedText (limited Markdown), version, publishedAt, active, lastChange}`. Swap the organizer's staged `openapi.next.json` into `openapi.json` if it contains `/api/v1/club-pages` and `pending.json` does not redefine it; otherwise add the four routes to `pending.json` (mocks-first) and keep fixtures Ajv-checked. MSW fixtures: the three Cànic seed pages (`RULES` active with the marker + a short fictional body, `IMAGE_CONSENT` active, `PRIVACY` inactive draft), `STALE_VERSION` on a stale `PATCH`.
1. **D11 card «Pàgines del club»** (clubs-admin, `/parametres`, ADMIN): list of pages with title (current locale), status chip («publicada» · «esborrany»), `versió n · dd/mm` and a «+ Pàgina» action for a free key (`[a-z0-9-]{2,40}`, unique; the four fixed keys are always listed even when they do not exist yet, as «sense contingut»). Row → **editor drawer/page** with per-locale tabs (club locales), Markdown textarea with a rendered **preview** (same limited Markdown rules as the API: headings, paragraphs, bold/italic, lists, links — the preview strips anything else), title per locale, [Desa l'esborrany] (`PATCH` without activating), [Publica] (`active: true`; confirmation «Es publicarà la versió n+1 — els consentiments futurs hi faran referència» when `key ∈ {RULES, PRIVACY, IMAGE_CONSENT}`), [Desactiva] for free pages only (the four fixed keys cannot be deactivated from the UI once published, only edited). Errors: `STALE_VERSION` → «Un altre administrador ha editat aquesta pàgina — recarrega», `VALIDATION_ERROR` field errors under the textarea. Pages whose body still contains the R-05-21b marker show an inline warning «Text provisional — pendent d'omplir» in the list and in the editor.
2. **Screen 30 «Info» (clubs app)**: tabs FAQ · Normes (`RULES`) · one tab per other **active** page in `GET /club-pages?active=true` (title in the member's locale, fallback to the club default), rendered Markdown, «Actualitzat el dd/mm/yyyy» from `publishedAt`; FAQ tab unchanged. The «Normes» tab is hidden when `RULES` is not active.
3. **Links**: the E2-W05 disabled «Normes del club» link becomes the row action of the card; `apps/clubs-admin` sidebar/search entries as for FAQ. The public route (`/public/{clubSlug}/pages/{key}`) is consumed by the signup screen in E3 — expose a typed client function now, no screen.
4. i18n keys ca/es/en for every literal (no literal in code; `i18n:check` green); the marker text itself comes from the API body (never from the front).
