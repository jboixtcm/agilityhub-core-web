# E1-W02 · Onboarding screen «Completa el teu perfil» (first access of imported/migrated accounts) + policy re-consent pop-up

## Objective
The decided first-access experience (Jordi 05-09): a profile-completion screen with the mandatory privacy checkbox, and the pop-up for new policy versions (A12).

## Spec references
S01 §14 (onboarding), `docs/DECISIONS_PENDENTS.md` A4, A12 · `docs/legal/POLITICA_PRIVACITAT_AGILITYHUB_ID.md` (linked, never inlined) · `GET/PUT /me/onboarding` contract (E1-T06).

## Context to load
S01 §14 · DECISIONS A4/A12 · the onboarding contract in the generated types · `packages/ui` components · this file.

## Steps
1. Route `/benvinguda` in `apps/clubs` (and an equivalent modal in `apps/clubs-admin`): shown after login when `me.account.onboardingPending`; contract (S01 §6 v0.3, api snapshot E1-T01): `GET /me/onboarding` → `OnboardingState {pending, postponeRemaining, requiredConsent: {policy: PLATFORM|CLUB, version, url} | null, fields[]: {key, value, required}}` (render one input per `fields[]` entry — `name`, `locale` (select of product locales), `phone` — prefilled from `value`, `required` only marks the label: the data part can be skipped with «Ho faré més tard»), mandatory checkbox «He llegit i accepto la política de privacitat» linking `requiredConsent.url`, [Continua] → `PUT /me/onboarding {consentAccepted: true, consentVersion: requiredConsent.version, fields?: {…}, imageConsent?}`; errors `VALIDATION_ERROR` (checkbox), `CONSENT_VERSION_OUTDATED` (reload the state and ask again). The screen has no mockup: use the design system, mobile-first, and propose the literals in the report (`ca`, `es`, `en`).
2. Policy version bump: non-blocking pop-up with the same checkbox and «Més tard» (`POST /me/onboarding/postpone` → new `OnboardingState`) while `postponeRemaining > 0`; blocking (no «Més tard») when it reaches 0.
3. Guard: routes other than `/benvinguda`, `/entrar`, `/activacio` and legal pages redirect to `/benvinguda` while `pending` and `postponeRemaining == 0` (a postponed policy bump does not block navigation).
