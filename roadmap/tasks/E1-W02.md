# E1-W02 · Onboarding screen «Completa el teu perfil» (first access of imported/migrated accounts) + policy re-consent pop-up

## Objective
The decided first-access experience (Jordi 05-09): a profile-completion screen with the mandatory privacy checkbox, and the pop-up for new policy versions (A12).

## Spec references
S01 §14 (onboarding), `docs/DECISIONS_PENDENTS.md` A4, A12 · `docs/legal/POLITICA_PRIVACITAT_AGILITYHUB_ID.md` (linked, never inlined) · `GET/PUT /me/onboarding` contract (E1-T06).

## Context to load
S01 §14 · DECISIONS A4/A12 · the onboarding contract in the generated types · `packages/ui` components · this file.

## Steps
1. Route `/benvinguda` in `apps/clubs` (and an equivalent modal in `apps/clubs-admin`): shown after login when `me.onboardingPending`; fields from `GET /me/onboarding` (prefilled, all optional), mandatory checkbox «He llegit i accepto la política de privacitat» with the link, [Continua] → `PUT /me/onboarding`; the screen has no mockup: use the design system, mobile-first, and propose the literals in the report (`ca`, `es`, `en`).
