# E0-W06 · App shells: clubs (PWA, tab bar), clubs-admin (sidebar), id — themed per host without flash, gated by modules and roles

## Objective
Work package WP-02-C (apps part) and test **T-02-14**: the three apps boot from `/branding`, apply the club theme before the first paint, and show the navigation of the mockups filtered by modules and roles. Every screen route exists as an empty placeholder so later tasks only fill content.

## Spec references
S02 WP-02-C, T-02-14 · `docs/PLA_FRONTEND.md` §5 (screen → route → spec map) · mockups `docs/pantalles/mobil/03-inici-abonat.html|png` (tab bar), `docs/pantalles/mobil/04-reservar-activitats-i-classes.html` (tab bar with 6 tabs), `docs/pantalles/escriptori/D1-tauler-de-control.html|png` (sidebar groups).

## Context to load
PLA_FRONTEND §5 · the three mockup files above · `docs/specs/00-transversal/CATALEG_MODULS.md` · this file.

## Fixed content (from the mockups)
- Mobile tab bar (6 tabs, in this order, Catalan labels): **Inici · Reservar · Entrenaments · Avui · Perfil · Info** (icons `home`, `cal`, `cone`, `day`, `user`, `info`). `Entrenaments` requires module `FREE_TRAINING`; `Info` requires `FAQ` (or club pages); `Avui` is the instructor's day view (role INSTRUCTOR) — hide it for members.
- Desktop sidebar groups and entries: **Tauler** · **Persones**: Preinscripcions, Abonats, Gossos, Inactivitats i baixes, Seguiment alumnes · **Camp**: Plantilla setmanal, Calendari de classes, Entrenaments, Activitats · **Gestió**: Facturació, Modalitats i tarifes, Comunicats · **Configuració**: Pistes, Instructors i administradors, Paràmetres. Entries without mockup, gated by role/module: Recorreguts (`COURSES`), Auditoria (ADMIN), Consola (platform role). Header with club name/logo, language selector, user menu.

## Steps
1. `packages/ui/src/modules.ts`: map `Module → { routes[], tabs[], menuEntries[] }` used by both apps (single source for gating).
2. `apps/clubs` (PWA): `index.html` inline script that reads the last `branding` cached in `localStorage` (key per host) and sets the CSS variables **before** React mounts (no flash), then the app refreshes from `/branding` and updates the cache; `vite-plugin-pwa` with a **dynamic manifest** pointing to the core `/api/v1/manifest.webmanifest`; `TabBar` per the fixed content; routes for every mobile screen of PLA_FRONTEND §5 rendering `EmptyState` «Aviat» (placeholders keep the mockup's screen number in a code comment); a minimal `/acces` page (email + password, password grant) until E1 replaces it.
3. `apps/clubs-admin`: `Sidebar` per the fixed content with placeholder counters, routes for every desktop screen (placeholders), minimal login page.
4. `apps/id`: minimal landing with the AgilityHub brand (the real app is E1).
5. `packages/i18n` namespace `shell` with all labels in `ca`, `es`, `en`.
6. Playwright e2e in `apps/clubs` and `apps/clubs-admin` (with MSW in the browser): (a) host Cànic → `--ah-color-primary` equals the Cànic primary at `DOMContentLoaded` (before the first React paint); (b) host mínim → AgilityHub theme and the `Entrenaments` tab absent when `FREE_TRAINING` is not in `modules`; (c) manifest carries the club name; (d) admin: role INSTRUCTOR does not see the «Configuració» group.
