# E0-W01 · Monorepo skeleton: pnpm + Turborepo, three apps, four packages, lint/format/test tooling

## Objective
A monorepo where `pnpm turbo run lint typecheck test build` is green, with the apps and packages every later task fills in.

## Spec references
`docs/PLA_FRONTEND.md` §1–3 · `docs/decisions/ADR-001` · `docs/decisions/ADR-011` (i18n).

## Context to load
`AGENTS.md` · `docs/PLA_FRONTEND.md` · this file.

## Fixed conventions (do not change)
Node **22 LTS** (`.nvmrc`), pnpm **9** (`packageManager` field), Turborepo, React **19**, TypeScript **strict**, Vite, Tailwind **4**, Vitest + Testing Library, Playwright, MSW, ESLint flat config + Prettier, husky + lint-staged + commitlint (conventional commits). Package names `@agilityhub/ui`, `@agilityhub/i18n`, `@agilityhub/api-client`, `@agilityhub/auth`; apps `clubs`, `clubs-admin`, `id`.

## Steps
1. `pnpm-workspace.yaml`, `turbo.json` (pipelines `lint`, `typecheck`, `test`, `build`, `e2e`, with `build` depending on `^build`), root `package.json` scripts (`lint`, `typecheck`, `test`, `build`, `i18n:check`, `api:generate`, `e2e`).
2. `apps/clubs`, `apps/clubs-admin`, `apps/id`: Vite + React 19 + TS + Tailwind 4 templates, each rendering a placeholder page and one Vitest test; `apps/clubs` with `vite-plugin-pwa` installed (configured in E0-W06).
3. `packages/ui`, `packages/i18n`, `packages/api-client`, `packages/auth`: TS packages exporting sources through `exports` (no build step needed inside the monorepo), each with one trivial test. Reserve `packages/course-core` and `packages/course-ui` (empty README explaining they arrive with E0-W08 / E9).
4. `packages/config`: shared ESLint flat config (react, react-hooks, jsx-a11y, import/order, `@typescript-eslint` strict) including a **`no-restricted-syntax` rule that forbids literal colors** (`/#[0-9a-fA-F]{3,8}\b/`, `/rgba?\(/`, `/hsla?\(/`) in `*.ts`, `*.tsx`, `*.css` outside `packages/ui/src/tokens.css`; shared `tsconfig.base.json`; Prettier config.
5. husky pre-commit (`lint-staged`: eslint + prettier) and commit-msg (commitlint conventional).
6. `README.md` (install, run, test), `.editorconfig`, `.gitignore`, `CHANGELOG.md` (Keep a Changelog).
