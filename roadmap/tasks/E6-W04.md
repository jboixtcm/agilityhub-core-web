# E6-W04 · E6 integration (front)

## Objective
Work package S10 WP-10-G (front half): the E6 screens (20, 21, 22, 25, 26, D12, D13, D14) run in the browser against the **real published core** with the E6 demo seed of api E6-T04 — the Monday 8:30 class with Laura, Marc, Anna and Eva booked and Pau waiting, two tasks with an attachment on Duna, a member note and a month of history shaped to produce the card's metrics. The attendance sheet is passed from the mobile and from D12 through the same contract, «ha avisat» really cancels the booking and frees the seat, the P8 and P3 processes are driven from the D11 card with the clock advanced so the class finishes and N-19 goes out, and everything lands where the gate expects it.
