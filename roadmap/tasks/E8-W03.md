# E8-W03 · D10 drawers, «Inactivitats i baixes», D5 leave columns

## Objective
Work package S13 **WP-13-E** plus the administrative half of S12 **WP-12-G**. From the member record the administrator changes the payment method, changes the plan (with the 40 % entry discount when a 10-session pack member becomes a full member), creates, approves, denies, modifies, terminates or cancels an inactivity period, decides a leave request or schedules a leave directly, cancels a planned leave and reactivates a member who has left. A new «Inactivitats i baixes» page lists both queues with the universal-list pattern and a menu badge, D5 gains the leave columns and the shared «Baixes previstes» system view, and the D8/D11 billing values (`billing.sepa.collectionDayOfMonth`, `billing.cashInvoicing`, entry fee, pack expiry) are **verified, not rebuilt**. Mocks-first on the S12 + S13 contract of api E8-T01; D10 fidelity against the V7 mockup, the new page built with the design system.
