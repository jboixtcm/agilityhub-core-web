### Assumptions
1. **`smarter-writer.test.ts` fix.** The test was changed; the logic was not.
   - The origin test built 5 control points for `t2`.
   - The writer (`expectedTunnelControlPointCount`), used by both `validateDraft` and `validateSmarterDocument`, requires 3 for `t2`/`t3s`/`t3`, and the importer maps `t2` to a 2 m tunnel.
   - Provenance shows both files are unmodified at `65126cf`, so the test was already failing at the origin.
   - The change is commented in the test.
2. **Byte-identical over lint conformity.** «Unchanged behaviour» and a diffable origin weighed more than rewriting 486 lint findings by hand. Hence the scoped ESLint block and the `.prettierignore` entries. Prettier 3.9 would reformat 9 origin files even under the origin's single-quote settings.
3. **AprilTag colours are print artwork, not themed UI.** The fiducial must be pure black on white to be detected, and the marker page is a standalone SVG file where CSS variables do not apply. Hence the narrow color-rule exemption.
4. **`legacy/db.ts` is not exported.** «For reference only» was read as: not re-exported from `index.ts` and no subpath export. The file still typechecks.
5. **The `importer:summary` script was dropped** (the module and its `./cli/importer-summary` export are kept). The origin ran it with `tsx`, which is not in this lockfile and was not added.
6. **Fixture privacy.** The fixtures carry `designer: ""`. Some titles/file names carry a course designer's name as published in public competition courses; for example Wald's title `…-oliver-gustke-2`. The task explicitly asks for these 4 real files, so they were kept verbatim.
