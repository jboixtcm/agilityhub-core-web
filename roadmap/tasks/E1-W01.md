## Objective
Work package WP-01-F: the real access flow of the student PWA and the backoffice login, pixel-faithful to the mockups, against MSW first and the core afterwards.

## Steps
1. Screen 01 `/entrar` (spec route; also fix the `/acces` redirect left in `packages/auth` by E0-W05 → `/entrar`): email → «Envia'm l'enllaç» (`POST /auth/magic-link`, always success message), «Tinc contrasenya» reveals the password field (password grant), «Apunta-t'hi» only when `branding.signup.enabled`; `429` → countdown from `Retry-After`; exact literals of the mockup in `ca`, `es`/`en` in the same PR (T-01-18).
2. Screen 02 `/activacio` (landing of the magic link `?token=…&purpose=`): «Benvinguda, {name}!» with gender-aware greeting (`gender` from `/me`; non-binary → masculine as the spec says), [CONTINUAR] before the optional password block; `purpose=RESET` → «Ja hi ets» variant (T-01-19).
3. Screen 03b `/perfil-acces`: profile choice when `profiles.length > 1` and no remembered default; «Recorda la meva tria» → `PUT /me/profile {remember: true}`; switching profile later from screen 12 (T-01-20).
4. Screen 12 rows: «Contrasenya» (set/change with `current` only when a hash exists; error codes → messages), «Idioma» (`PATCH /me {locale}` restricted to `branding.locales`), «Sessions» (list + revoke), «Tanca la sessió» (revoke + clear storage) (T-01-21).
5. Impersonation banner in `apps/clubs` when `me.impersonation` is present («Estàs veient l'app com {member}» + «Surt»), and handoff entry point «Obre el backoffice» for accounts with ADMIN/INSTRUCTOR profiles (`POST /auth/handoff` → open `clubsadmin` host with the code).
6. `apps/clubs-admin` login page: magic link + password, same components; handoff landing route that exchanges the code.
7. MSW handlers + fixtures for every endpoint used; i18n namespace `auth` complete.
