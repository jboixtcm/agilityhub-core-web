### Assumptions
1. **Method labels** come from `admin-census:signupReview.paymentMethod.{type}`, not from the view's `label`, so the drawer, the «Pagament» row and the readmission block read the same in the UI language. On the real core both give «Domiciliació» and «Efectiu».
2. **An applicant's method that is no longer assignable** stays in the select as a disabled, preselected option. It is kept only if the admin leaves the select alone. The SEPA fields hide while SEPA is not assignable, because the api would answer 422 to any SEPA data.
