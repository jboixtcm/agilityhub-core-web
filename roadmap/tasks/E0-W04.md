# E0-W04 · packages/api-client: generated types, fetch client, ApiError, TanStack Query, MSW mocks

## Objective
One typed client for the whole front, generated from the core OpenAPI snapshot, with mocks that let every screen be built before its backend exists.

## Spec references

## Context to load

## Steps
1. `pnpm api:generate` → `openapi-typescript` from `API_SPEC` (default `../agilityhub-core-api/docs/openapi/openapi.json`, fallback to the stub) into `packages/api-client/src/generated/schema.d.ts` (committed); `openapi-fetch` client with `baseUrl` from `VITE_API_URL` (default `https://core.agilitydoghub.com/api/v1`), headers `Accept-Language` (current locale) and `Authorization` (injected by `packages/auth` through a middleware hook), automatic `Idempotency-Key` (UUID v4) on POST operations flagged with `x-idempotent` or listed in a config.
2. `ApiError { code, message, details, traceId, status }` + `isApiError(e, code?)`; every non-2xx becomes an `ApiError`; network failures → `code: NETWORK`.
3. TanStack Query: `createQueryClient()` (retry only on 5xx/network, `staleTime` 30 s), hooks `useBranding()` (also feeds `BrandingProvider`), `useMe()`; query keys namespaced by host.
4. MSW: `packages/api-client/src/mocks/handlers.ts` for `/branding`, `/me`, `/oauth2/token`, `/health` with fixtures `branding-canic.json`, `branding-minim.json`, `me-admin.json`, `me-member.json`; `browser.ts` worker (enabled with `VITE_MOCK=1`) and `server.ts` for Vitest; a `mockScenario(name)` helper to switch fixtures in tests.

### Assumptions
- The sibling snapshot exists but currently contains only `GET /api/v1/health`; it is therefore incomplete for this task. The committed fallback stub transcribes the `/branding` shape from backend E0-T05 and `/me` plus password-grant shapes from backend E0-T09. The generator prefers a complete `API_SPEC`, then a complete sibling snapshot, and otherwise uses the stub.
- Generated core paths strip the `/api/v1` prefix because `VITE_API_URL` already includes that prefix. `/oauth2/token` remains unprefixed and can use a client configured with the AgilityHub ID base URL.
- `NETWORK` is a client-only code explicitly required by this task; it is also used when a non-2xx response violates the standard JSON error contract and has no backend `code`.
- The Cànic JSON fixture remains a superset of the E0-W02 fixture shape so the existing UI gallery stays compatible while the API fields are available to MSW.
- `normalizeBranding()` maps the generated response into the flat design-system shape: `club.slug` supplies the design-system `clubId`, `primaryFg` maps to `onPrimary`, `surface2` maps to `surfaceAlt`, and `surface` supplies `background`.
