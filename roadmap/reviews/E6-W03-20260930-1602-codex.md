# Review E6-W03 — needs changes

## Findings

1. **major** `apps/clubs-admin/src/followup/FollowUpPage.tsx:398` — Filter options and counts come exclusively from `page: 0, size: 50`; `totalPages` is ignored. Members/dogs appearing only in older rows cannot be selected. Even “read” can disappear when the first 50 rows are unread. An in-memory probe with 51 distinct members returned only 50 options. This leaves step 5 / R-10-13 incomplete. Paginate relation values fully and derive enum/boolean options from the contract; add a multi-page test.

2. **major** `apps/clubs-admin/src/followup/FollowUpPage.tsx:460` — Per-row read failures are discarded: `.then(unread.refresh, unread.refresh)` handles rejection like success, after optimistic updates and navigation. A rejected `STALE_VERSION` or network failure provides no error or retry, although the item remains unread. This violates the task’s error-handling convention and R-10-13. Handle failures through a mutation owner that survives navigation, reconcile optimistic state, and expose translated feedback/retry. Test a rejected read.

3. **major** `packages/ui/src/attendance.tsx:254` — The new attendance badge uses generic tone text over a 14% tinted background, failing AGENTS rule 6’s AA text contrast. Calculated from the shipped fixtures: dark-theme “no presentat” is approximately **4.28:1**; the light fixture’s green/yellow labels are **4.39:1 / 3.94:1**, below the **4.5:1** required for this small text. The contrast tests cover circles only. Give the badge accessible foreground/background tokens and test both themes.

4. **minor** `apps/clubs-admin/src/followup/FollowUpPage.tsx:452` — Clicking an already-read row sends no read request. If its note changes while D14 remains open, the counter refreshes but the list does not; opening that stale row therefore leaves the updated note unread even after D13 displays it. Step 5 requires a per-row read on activation. Always send the read request; condition only the optimistic decrement on the displayed flag. Test an intervening note update.

5. **minor** `apps/clubs-admin/src/followup/FollowUpPage.tsx:359` — The required `authorAccountId` filter is absent. Report Q5 acknowledges the contract limitation, but step 5 is still only partially implemented despite the “Steps 0–14 are done” claim. Resolve the value-source contract with the organizer and implement the creator filter, or explicitly obtain a scope deferral.

6. **minor** `apps/clubs-admin/src/instructor/WeekAgendaPage.tsx:461` — Training cells truncate the guide/dog names without a tooltip or expandable detail. The committed `D12-agenda-1280.png` visibly clips “Pau + Blat” and “Sergio + Thai”; these plain cells cannot be opened to recover the text. Step 3 / R-10-15 requires those identities to be shown. Preserve half-height rendering while making the complete text accessible, and verify actual clipping in the browser test.
