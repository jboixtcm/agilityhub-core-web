# Review E7-W03 — minor issues

## Findings

1. **minor** `e2e/core/e7-core.spec.ts:2605` — The N-13 test swallows delivery-settlement failures and only excludes EMAIL status `SENT`. An incorrectly queued email can therefore pass while the mailbox is temporarily empty, then arrive later. This does not establish step (h)’s preference suppression guarantee (R-11-04 / R-11-16). Assert EMAIL is exactly `SKIPPED_BY_PREFERENCE`; handle pending PUSH deliveries separately.

2. **minor** `e2e/core/e7-core.spec.ts:2389` — If N-08a incorrectly becomes non-mandatory, the `TEMPLATE_MANDATORY` probe silently disappears and the assertion loop skips it. The suite can remain green despite breaking R-11-12 and round-2 correction #4’s requirement to assert every named code. Assert `detail.mandatory === true` and run the probe unconditionally.

3. **minor** `e2e/core/e7-core.spec.ts:2437` — The new error-code assertions execute before the rollback block. If the core mistakenly accepts an invalid write, the assertion throws before restoring the template/preference or deleting the invalid subscription. Those probe mutations are not tracked by the `afterAll` safety net. Put restoration in `finally` so the failure cleanup promised by step (j) actually executes.

4. **nit** `e2e/core/e7-core.spec.ts:1700` — Step (c) checks the edited notices on screen but captures neither language. Both committed notification screenshots were taken before the template edit, so they cannot provide the two screenshots requested by step 6 for that gate item. Capture the new Catalan and Spanish cards with the appended template marker and reference them in the report.
