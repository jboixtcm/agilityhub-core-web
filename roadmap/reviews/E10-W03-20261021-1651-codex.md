# Review E10-W03 — minor issues

## Findings

1. **minor** `apps/clubs-admin/src/console/tabs/ParametersTab.tsx:140` — A successful PUT immediately closes the editor while `onSaved` starts an unawaited reread. If that GET fails, the draft is discarded and the list retains its previous value. Round 2, point 3 explicitly requires keeping the draft after this failure; the report claims this is covered, but the regression only checks the error and disabled controls. Retain the submitted value until rereading succeeds, and assert its preservation in the test.

2. **minor** `packages/api-client/src/mocks/console-handlers.ts:1359` — The support mocks do not enforce tenant isolation: DELETE accepts any ADMIN for either global fixture grant, creation returns the same token for every target club, and `supportMe()` always supplies the original admin fixture’s club. Consequently, the tests cannot detect targeting or revoking another club’s grant. S17 R-17-10 requires a foreign grant to return 404. Index mock grants by token and club, validate the caller’s tenant, and add a two-club regression. This is a mock/coverage defect, not evidence of a production authorization bypass.
