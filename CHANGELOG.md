- The planning mocks now generate the next two weeks in draft (D4b; one with an inconsistency), so D3 proposes the fourth week; week generation creates the draft class sessions and `classCounts` come from them; `ADMIN_TEXT_REQUIRED` speaks of the notice text in ca/es/en; instructors see «Calendari de classes» (E4-W02).
- D2 shows the required «Data del proper rebut» for a pending member from the proposed catalog plan type (the core sends no `member.plan` before validation), lays level and date on one row, shows signup warnings as compact header badges, and compacts the masked account to `···· 1234` (E3-W03 round 2).
- D3 edit mode queues the class PATCHes and sends each one with the latest template version, reloads the template and remounts the card on `STALE_VERSION`, and puts the form back to the saved class when a PATCH fails; failed loads of coverage, weeks or generation candidates show a toast with [Torna-ho a provar]; band errors land on the field that caused them; an unknown D3b `:dayOfWeek` is rewritten to the template's first day (E4-W01 round 2).
- `Level.progression` (ruling E29) is declared mocks-first through the new `x-schema-overlays` section of `pending.json` (the generator fails once the snapshot publishes the property); the D3 description preview and the MSW resolver count «{first} i sup.» over progression levels only, the mock resolves `displayDescription` in the reader's language («y sup.», «and up»), «Teràpia» is outside the progression in the mock catalog, and template fixtures use «F i sup.» for {F, G} (E4-W01 round 2).
- The Clubs Admin API client sends the UI language as `Accept-Language` instead of the browser language (E4-W01 round 2).
- `scripts/e2e-docker.sh` copies back only the evidence files written by the run for the `in_progress` task(s) (override with `E2E_EVIDENCE_TASK`), so other tasks' PNGs and the executor's logs are no longer overwritten (E4-W01 round 2).
- The shared ESLint config has a scoped block for the recovered course packages, which stay byte-identical to the origin. It switches off style and strictness rules only. The color rule is off only for the printable AprilTag modules. `.prettierignore` excludes those packages' sources, tests and fixtures (E0-W08).
- `@agilityhub/course-core` and `@agilityhub/shared-types` typecheck with the base `exactOptionalPropertyTypes: true`, like the apps that consume their sources; two marker-page option interfaces in `marker-svg.ts` accept `| undefined` (type-only). The AprilTag colour exemption in the ESLint config cites the organizer's ruling and defers the page chrome colours to WP-16-E′ (E0-W08 round 2).
- D11 keeps parameters that the core sends with `module: null`; `pnpm e2e:core` defaults `CORE_URL` to the local stack and accepts an evidence subdirectory and an optional spec-file list; the E2 real-core D3 check follows the real templates page (E3-W03 round 2).
